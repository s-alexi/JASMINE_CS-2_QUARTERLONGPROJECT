# Project Title "Rock, Paper, Scissors, and MORE!"


## Project Description:
This will be a simple python program to cure your boredom. Now in our opinion, Rock, Paper, Scissors is VERY very boring on its own. But what if we added a twist? This program will add spice and fun into the original game by adding more "characters".

## Problem Statement:
Rock Paper Scissors is a simple and common game that can become boring when played repeatedly with only three choices. Because of this, our group plans to create a Python program that adds more options and choices to make the game more fun and interesting. The program will allow players to choose from different options while still following the basic idea of Rock Paper Scissors. This will make the game more interactive and give players more variety when playing.

## Project Objectives:
For our game, we decided to add a twist and to revamp the classic game "Rock, Paper, Scissors!" by widening the character selection and roster to refresh its gameplay all while maintaining the nostalgia you get from the original.

## Features: 
- Multiple Game Modes: The program offers at least two distinct gameplay modes, including a standard Classic Mode and a specialized Lock-in Mode.
- Expanded Character Selection: Players can choose beyond the traditional gameplay of "Rock, Paper Scissors" by selecting the additional characters soon to be added, widening the roster.
- In-Game Guide: A built-in "Guide" option is available from the main menu to help players understand the rules or additional elements.
- Score Tracking: The program tracks the player's performance and displays a total score summary when exiting a game session.
- Easy Exit: Players can easily exit back to the main menu from the character selection screen and close the program entirely.

## Planned Input/Output:
### Input:

- Menu Selection Input: A letter choice from A to  D typed by the player to navigate the main menu.
- Character Selection Input: A letter choice A to E typed by the player to pick a combatant or return to the menu.
- Gamemode Characters: Requires the user to input their chosen character while playing the gamemode.

### Output:

- Main Menu Interface: A clean, four-line text display presenting Lock-in Mode, Classic Mode, Guide, and Exit.
- Character Roster Interface: A five-line text choice menu showing Rock, Paper, Scissors, etc.
- Battle Evaluation Message: A result sentence that explicitly states both actions and the outcome (e.g., Does Paper beat Rock(enemy) ? Yes ! You won !).
- Session Score Display: A final line tracking performance when a match loop terminatesd (e.g., Your Score is 1 !).
